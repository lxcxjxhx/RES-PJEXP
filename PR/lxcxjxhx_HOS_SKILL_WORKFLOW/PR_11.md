## Summary

Redesign the HOS-IP-Writing skill system from v1.0 to v2.0, addressing structural inconsistencies, phantom references, content bloat, and lack of cross-skill collaboration.

Closes #8

## Problems in v1.0

1. **Structural inconsistency**: Each sub-skill had different format and structure, making it hard to navigate
2. **Phantom references**: SKILL.md files referenced \	emplates/\ and \workflows/\ directories that were disconnected from actual execution
3. **Content bloat**: Sub-skill files contained verbose, non-executable pseudocode and redundant template content
4. **No cross-skill collaboration**: No mechanism for sub-skills to share context or pass artifacts
5. **Missing quality gates**: No acceptance criteria for each execution phase
6. **No ecosystem integration**: No defined integration points with other HOS modules

## Changes

### New: Shared Context Layer (\shared/\)
- \context-schema.md\ — Cross-skill data passing protocol (project/author/output fields)
- \quality-gates.md\ — Acceptance criteria for each phase of each sub-skill
- \output-conventions.md\ — Unified output format and file naming standards
- \hos-integration.md\ — Integration points with Sec-Engine, Fuck-Demo, Silly-Mock, Vibe-Guard

### New: Cross-Skill Pipelines (\pipelines/\)
- Academic full pipeline: paper → review → submission
- Tech influence pipeline: blog → book → review
- IP protection pipeline: patent → copyright → paper
- Content factory pipeline: blog(batch) → review → book
