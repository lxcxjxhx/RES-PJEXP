## 概述

新增 **S-12-HOS-Critic-Review**：AI 原生六维毒舌专家评审 Skill——输入任意技术对象（GitHub 仓库/论文/文章/方案/License/数据集），分钟级输出可追溯、带证据、可决策的专家级评审。

## 核心能力

- **七 Agent 流水线**：Discovery → Chunk → Analyzer → Evidence → Critic → Judge → Report
- **泛化语义切片引擎 v2**：一套统一管线（Unitize→Constrain→Annotate）适用全部对象类型，单元细化到语义块并带角色标注（claim/evidence/method/…）；tree-sitter / PyMuPDF 等工具按需注入（干什么事调用什么工具）
- **六维评分**：Technical / Innovation / Engineering / Ecosystem / Risk / Strategic，跨对象可比，打分可复核
- **5 类分析器**：GitHub（生态指标）/ Paper（Semantic Scholar + PyMuPDF）/ License（SPDX）/ Dataset / Code（semgrep + 正则兜底）
- **独立体系**：HCR-FIND 编号、Review Store 持久化、三报告模板（Quick/Expert/Academic）+ 机器 JSON
- **可编程接入**：事件流（--events）、run 命令 + --until 截断、MCP server（JSON-RPC stdio）
- **零依赖可跑**：智能环节（批判/评分/毒舌）由宿主 LLM 执行；无任何外部工具也能出完整报告（降级如实记录）
