## PR 描述

## Summary

Adds configurable connection pool management to HTTPAdapter with pool_size/pool_block parameters, health checks, pool statistics, and reset capability.

## Problem

The HTTPAdapter had no explicit connection pool configuration or monitoring. Users could not control pool size, check pool health, or get statistics about connection usage.

## Changes

- Added `pool_size` (default 10) and `pool_block` (default True) parameters to `HTTPAdapter.__init__`
- Configured `httpx.Limits` with `max_connections`, `max_keepalive_connections`, and `keepalive_expiry`
- Added `get_pool_stats()` for monitoring pool usage
- Added `check_pool_health()` for health checks
- Added `reset_pool()` to reset pool and clear stats
- Added request counter tracking in `_pool_stats`
- Added tests in `tests/test_http_adapter.py`
