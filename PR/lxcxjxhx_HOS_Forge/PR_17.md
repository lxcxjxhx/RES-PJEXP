## Description

This PR fixes two Windows compatibility issues that prevent OpenHands from running correctly on Windows systems.

### Issues Fixed

1. **File encoding in version.py**: Added explicit UTF-8 encoding when reading pyproject.toml to prevent UnicodeDecodeError on Windows systems with non-UTF-8 default encoding.

2. **SQLite URL path separator in db_session_injector.py**: Replaced backslashes with forward slashes in persistence_dir path before constructing SQLite URLs. SQLite URLs require forward slashes, but Windows Path objects use backslashes, causing database connection failures.

### Changes

- \openhands/app_server/version.py\: Added \encoding='utf-8'\ parameter to \open()\ call
- \openhands/app_server/services/db_session_injector.py\: Added \.replace('\\\\', '/')\ for persistence_path in both \get_async_db_engine()\ and \get_db_engine()\ methods

### Testing

- Verified on Windows 11 with Python 3.12
- SQLite database connections now work correctly
- Version detection works correctly regardless of system default encoding
