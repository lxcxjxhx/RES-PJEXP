## Summary

- Add knowledge base vector search with FAISS and sentence-transformers

## Security Tools Implementation
- **NmapTool**: Complete command execution with multiple scan types (TCP SYN, TCP Connect, UDP, Ping, Comprehensive), port ranges, service version detection, OS detection, timing templates, NSE scripts, and XML output parsing
- **SemgrepTool**: Complete command execution with rule configuration, language filtering, severity filtering, JSON/SARIF output formats, and structured finding extraction (CWE, CVE, OWASP metadata)
- **NucleiTool**: Complete command execution with template selection, tag filtering, severity filtering, rate limiting, concurrency control, and JSON output parsing
- All tools include availability detection, timeout control, error handling, and graceful degradation

## Knowledge Vector Search
- **Embedding Generator**: Integration with sentence-transformers (default: all-MiniLM-L6-v2, 384 dimensions), batch processing support, CPU/GPU/MPS device selection
- **Vector Store**: FAISS-based implementation with FlatL2 and IVFFlat index types, similarity search with threshold filtering, index persistence to disk
- **Semantic Search API**: Unified search interface with structured results (content, score, metadata), batch document addition
- **Knowledge Indexer**: Build index from files/directories, support 17 file types (.md, .py, .txt, etc.), text chunking (512 chars, 64 overlap), incremental updates based on file hash tracking
