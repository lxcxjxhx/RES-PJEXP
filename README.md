## About Me

</div>

<div align="center">
<table align="center" width="85%" style="margin: 0 auto;">
<tr><td style="padding: 24px; line-height: 1.8; font-size: 15px;">

**钱佳宏 (Qian Jiahong) · 上海**

三年前，我在 CSDN 写下第一篇安全笔记，记录一次应急响应的完整排查过程——从日志分析到最终定位攻击者 IP。那是"安全风信子"这个名字的起点。

后来，我把写博客的习惯变成了写开源工具的习惯。从第一个 PyPI 包发布时的忐忑，到在 HuggingFace 上微调出能理解攻击日志的模型，再到用 Multi-Agent 架构构建 HOS-LS——一个让 AI 自动分析代码漏洞、推理攻击链的系统。这条路从"记录"走到"创造"，从"个人笔记"走到 **168** 个被社区采纳的 Pull Request。

现在，我在 **信息安全 × 大模型工程** 的交叉地带全速前进：用 vLLM 部署生产级推理服务，用 MCP 协议构建可控的 Agent 系统，用 Prompt Engineering 把 LLM 变成安全分析师的副驾驶。

**1,467 篇原创文章** 不是数字——是 1,467 次"搞明白一件事"的承诺。
